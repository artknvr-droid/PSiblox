# 💚 Rokori PS

**Linux Roblox Launcher**

Welcome to Rokori PS, a community-built Linux launcher project by PS_Studios.

## Features

- Green and white PS design
- Cordial runtime detection
- Play Roblox button
- Runtime installation link
- Linux desktop support

## Requirements

- Linux
- Python 3
- Tkinter
- Flatpak
- Cordial installed separately

## Run

```bash
python3 src/main.py
```
